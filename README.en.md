# AIwear

#### Description
AIWear 是一个面向服装穿搭场景的 AI Web 应用，核心目标是将大模型能力接入真实业务系统。项目重点在FastAPI 业务、用户认证、图片处理仓库、对象存储、CLIP 支撑检索、RAG 问答和 SSE 流式输出，前端页面主要用于功能演示和接口联调。
